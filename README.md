One Wi-Fi network name that tells a whole story in 32 characters, written by a small Python program to `/output/entry.txt` for the make.fun bounty "Tell a Whole Story in 32 Characters".

The name:

> SheTookTheRouterNotTheKids

A divorce in one line: she walked out with the router and left the kids behind. The reader fills in the rest — the narrator, stuck with the children and no internet, staring at the network list.

## Run it

```sh
python3 main.py
```
